# Plano

Registrar a execução em `work/gran-import` com um arquivo por chamada. Reusar o ponto de consulta do Gran para coletar códigos de transporte, tempo e status. Usar apenas códigos e nomes de campos, sem registrar os objetos de erro nem os dados recebidos.

Acrescentar os valores de paginação nas validações do importador e o código do SQLite nas falhas locais. Validar com rede simulada e executar o script contra um banco temporário para conferir os registros.
