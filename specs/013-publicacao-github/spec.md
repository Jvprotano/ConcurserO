# Publicação no GitHub

- R1. Publicar o código do ConcurserO em um repositório público com descrição em português.
- R2. Uma cópia nova deve instalar, compilar e abrir a aplicação localmente com banco próprio.
- R3. O README explica como começar e aponta para os guias e especificações existentes.
- R4. Banco de uso, PDFs, backups, registros locais, credenciais e arquivos gerados ficam fora da publicação.

O aceite exige verificar a visibilidade, o commit remoto e a execução a partir do conteúdo versionado.
