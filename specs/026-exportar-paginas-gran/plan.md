# Plano

Adicionar `-ExportarPara` ao importador da IBFC. Reusar o percurso já existente e escolher entre saída JSON e SQLite. Gravar cada arquivo completo com nome que identifica página e hash do seu conteúdo.

Validar com respostas simuladas, incluindo HTTP 429 após uma página, retomada, repetição e versão de conteúdo distinta. Conferir o PowerShell sem acessar a conta do Gran.
