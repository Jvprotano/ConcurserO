# Resumos no ConcurserO

Em **Resumos → Novo resumo**, digite um título, escreva e clique em **Salvar resumo**. Use **Classificação e apostila** para vincular um assunto do edital, indicar uma classificação livre ou apontar para uma página do PDF do acervo. Na sessão de teoria, **Criar resumo deste assunto** abre o editor com os dados preenchidos em outra janela ou aba.

Busque pelo título, assunto, disciplina ou texto. Use **Arquivar resumo** para guardar um resumo fora da lista de ativos. Ele pode ser consultado e reativado em **Arquivados**.

## Backup e restauração

1. Com o [Google Drive para computador](https://support.google.com/drive/answer/10838124?hl=pt-BR) aberto e conectado à sua conta, crie uma pasta para os resumos dentro de **Meu Drive** no Explorador de Arquivos. Se preferir manter uma cópia local independente, use qualquer pasta local.
2. Copie o caminho completo da pasta pela barra de endereço do Explorador. Em **Resumos → Backup dos resumos**, cole o caminho em **Pasta para backup automático** e clique em **Usar esta pasta**.
3. Confira a data da última gravação no ConcurserO. O Drive administra o envio. Você pode conferir o arquivo na versão web do Google Drive depois da sincronização. O ConcurserO atualiza um arquivo por dia e por instalação, conservando as cópias dos dias anteriores. Os PDFs vinculados ficam no acervo.
4. Para restaurar, selecione o JSON em **Arquivo de backup** e clique em **Restaurar do arquivo**. Versões diferentes ficam lado a lado. O vínculo com o PDF abre o arquivo quando o mesmo cadastro está disponível no acervo de destino.

**Baixar backup** cria uma cópia manual em JSON para guardar onde quiser. Se a pasta automática ficar indisponível, os resumos continuam salvos no próprio ConcurserO. Quando a pasta voltar, use **Gravar cópia agora**.
